# Canteen Management System

This project is a canteen management application that focuses on making basic canteen operations easier to manage. The idea is to organize the application into different parts and handle user requests through a backend.

I worked on this project to get practical experience with Node.js, Express.js, and backend development.

## Tech Stack

- **Node.js** – Backend runtime.
- **Express.js** – Handling routes and API requests.
- **JavaScript** – Application logic.
- **Database** – Add the database actually used in this project.
- **Git & GitHub** – Version control.

## What I Worked On

- Setting up the backend using Node.js and Express.js.
- Organizing routes to handle different requests.
- Working on the application logic.
- Connecting backend operations with the relevant data source.
- Testing functionality and checking errors during development.

## Problems I Worked Through

### 1. Organizing Backend Routes

As the application has different operations, keeping the backend code organized is important. I worked with Express.js routes to separate request handling and make the code easier to maintain.

### 2. Handling Requests and Responses

I learned how the backend receives requests, processes the required logic, and sends responses to the client. This also helped me understand how to handle errors when something goes wrong.

### 3. Debugging

While working on backend functionality, I learned to check routes, request data, and server responses when something did not work as expected.

### 4. Connecting Application Logic

The different parts of an application need to work together correctly. Working on this project helped me understand how to organize backend logic and connect it with the application's data.

## What I Learned

- How Node.js and Express.js work together.
- How to organize backend routes.
- How HTTP requests and responses work.
- How to debug backend issues.
- Why input validation and error handling matter.
- How to structure a backend project for easier maintenance.

## Running the Project Locally

### Prerequisites

- Node.js
- npm
- Git

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/alifiya-shahi/cateen-management-system.git
   ```

2. Open the project folder:

   ```bash
   cd cateen-management-system
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Check `package.json` for the available scripts.

5. Configure any required environment variables.

6. Start the application using the appropriate command defined in `package.json`.
